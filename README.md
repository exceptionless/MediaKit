# MediaKit
[![Slack Status](https://slack.exceptionless.com/badge.svg)](https://slack.exceptionless.com) 

Media Kit for the Exceptionless project

## Logo

| File | Use |
| --- | --- |
| `exceptionless.svg` | Logo for light backgrounds |
| `exceptionless-dark-bg.svg` | Logo for dark backgrounds |
| `exceptionless-variable-color.svg`, `exceptionless-variable-color-min.svg` | Logo whose wordmark uses the CSS `currentColor`, for any background |
| `Exceptionless.png`, `Exceptionless_600.png`, `Exceptionless_350.png` | Logo for light backgrounds (transparent) |
| `Exceptionless2.png`, `Exceptionless2_600.png`, `Exceptionless2_350.png` | Logo for dark backgrounds (`Exceptionless2.png` is on `#181d29`; the others are transparent) |
| `Exceptionless.pdf`, `Exceptionless2.pdf` | Vector logo for print |
